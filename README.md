# Student_Expense_Tracker
A python-based Student Expense Tracker with expense management , monthly reports and data visualization. 

## Features
- Add new expenses
- View all expenses
- Delete expenses
- Categorize expenses
- Generate monthly reports
- Visualize expenses using graphs

## Technologies Used
- Python
- Jupyter Notebook
- Matplotlib

## Project Description
This project helps students manage their daily expenses and understand their spending habits through reports and visualizations.

## How to Run
1. Download the Python file.
2. Open it in Python or Jupyter Notebook.
3. Run the program.
4. Select the required option from the menu.
